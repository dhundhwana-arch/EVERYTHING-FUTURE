## Standard 22-Folder Module Schema (Adapted Per Domain)

Flagship modules adopt applicable folders from the canonical 22-slot schema (never creating empty folders):
`01_FUNDAMENTALS`, `02_ADVANCED_CONCEPTS`, `03_MATHEMATICAL_FOUNDATIONS`, `04_SYSTEM_ARCHITECTURE`, `05_ENGINEERING_METHODS`, `06_IMPLEMENTATION_GUIDES`, `07_SOURCE_CODE`, `08_TOOLS_AND_SOFTWARE`, `09_OPEN_SOURCE_PROJECTS`, `10_DATASETS`, `11_RESEARCH_PAPERS`, `12_BENCHMARKS`, `13_INDUSTRY_DATABASE`, `14_REAL_WORLD_APPLICATIONS`, `15_STANDARDS_AND_REGULATIONS`, `16_COST_AND_ECONOMICS`, `17_LIMITATIONS_AND_FAILURES`, `18_SAFETY_AND_RISK`, `19_RESEARCH_GAPS`, `20_UNSOLVED_PROBLEMS`, `21_FUTURE_DIRECTIONS`, `22_REFERENCES`.
