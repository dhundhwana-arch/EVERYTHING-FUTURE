# Mathematical Sciences — Standalone Technical Glossary

**Module:** `053_MATHEMATICAL_SCIENCES` | **Verification Status:** `VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **Runge-Kutta (RK4)** | 4th-order numerical integration method for solving ordinary differential equations accurately. |
| **Eigenvalue / Eigenvector** | Scalar lambda and nonzero vector v satisfying A*v = lambda*v, fundamental to dynamics and PCA. |
| **Convex Optimization** | Minimizing a convex objective over a convex set where every local minimum is globally optimal. |
| **Condition Number** | Sensitivity measure quantifying how input perturbations amplify numerical errors in linear systems. |
