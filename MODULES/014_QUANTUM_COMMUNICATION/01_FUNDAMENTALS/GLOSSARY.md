# Quantum Communication — Standalone Technical Glossary

**Module:** `014_QUANTUM_COMMUNICATION` | **Verification Status:** `PARTIALLY_VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **QKD (BB84)** | Cryptographic key exchange protocol whose security derives from quantum no-cloning and measurement disturbance. |
| **Quantum Repeater** | Device using entanglement swapping and quantum memory to overcome optical fiber photon loss. |
| **No-Cloning Theorem** | Fundamental theorem proving an arbitrary unknown quantum state cannot be copied identically. |
