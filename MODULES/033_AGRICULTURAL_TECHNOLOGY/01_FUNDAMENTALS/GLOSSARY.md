# Agricultural Technology — Standalone Technical Glossary

**Module:** `033_AGRICULTURAL_TECHNOLOGY` | **Verification Status:** `VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **Evapotranspiration (ETc)** | Combined soil evaporation and crop transpiration computed as ETc = Kc * ET0. |
| **Crop Coefficient (Kc)** | Dimensionless factor adjusting reference evapotranspiration for specific crop and growth stage. |
| **Precision Agriculture** | Using sensors, satellite imagery, and variable-rate inputs to optimize yield per drop and per hectare. |
| **Soil Moisture Deficit** | Amount of water needed to restore the root zone to field capacity. |
