# Advanced Chip Packaging — Standalone Technical Glossary

**Module:** `012_ADVANCED_CHIP_PACKAGING` | **Verification Status:** `PARTIALLY_VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **Chiplet** | Modular die implementing a subset of SoC functionality integrated on a shared package. |
| **2.5D Interposer** | Silicon or organic redistribution layer connecting multiple dies side-by-side at high bandwidth. |
| **Hybrid Bonding** | Direct copper-to-copper and dielectric-to-dielectric vertical wafer/die bonding without solder bumps. |
| **Co-Packaged Optics** | Integrating photonic transceivers directly inside the switch/accelerator package. |
