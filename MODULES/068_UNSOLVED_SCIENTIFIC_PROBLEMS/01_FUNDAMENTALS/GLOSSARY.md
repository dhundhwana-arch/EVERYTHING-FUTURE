# Unsolved Scientific Problems — Standalone Technical Glossary

**Module:** `068_UNSOLVED_SCIENTIFIC_PROBLEMS` | **Verification Status:** `PARTIALLY_VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **Open Problem** | Well-posed scientific or mathematical question lacking a verified solution or consensus mechanism. |
| **Falsifiability** | Criterion that a scientific hypothesis must allow conceivable empirical refutation. |
| **Anomaly** | Reproducible experimental observation contradicting predictions of the prevailing theoretical model. |
