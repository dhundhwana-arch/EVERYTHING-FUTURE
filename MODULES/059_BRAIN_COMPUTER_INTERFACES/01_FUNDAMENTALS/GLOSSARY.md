# Brain-Computer Interfaces — Standalone Technical Glossary

**Module:** `059_BRAIN_COMPUTER_INTERFACES` | **Verification Status:** `PARTIALLY_VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **EEG** | Electroencephalography recording scalp electrical potentials non-invasively with millisecond resolution. |
| **Motor Imagery Decoding** | Translating neural activity associated with imagined movement into cursor or prosthetic commands. |
| **Biocompatibility** | Ability of an implanted neural interface to operate safely without triggering destructive tissue scarring. |
