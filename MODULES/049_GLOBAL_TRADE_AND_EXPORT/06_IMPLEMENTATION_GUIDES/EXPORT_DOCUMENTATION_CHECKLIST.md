# Standalone Export Documentation Checklist (International Merchandise Trade)

**Module:** `049_GLOBAL_TRADE_AND_EXPORT` | **Owner:** DIVYESH BAMBHANIYA | **Verified:** 2026-11-19  
*Independently usable checklist aligned with [WTO](https://www.wto.org/) and [DGFT India Export-Import Guidance](https://www.dgft.gov.in/CP/?opt=export-import-guide).*

## Pre-Shipment Registration & Classification
- [ ] Valid Importer-Exporter Code (IEC) or national customs registration ID.
- [ ] Verified 6-digit HS Code (8-digit ITC-HS code for India via [DGFT ITC-HS](https://www.dgft.gov.in/CP/?opt=itchs)).
- [ ] Signed Proforma Invoice / Sales Contract specifying exact **Incoterms 2020** (e.g., FOB, CIF, DDP) and payment terms (L/C, TT, DP/DA).

## Mandatory Commercial & Shipping Documents
- [ ] **Commercial Invoice** (buyer/seller details, HS code, unit price, currency, Incoterm, country of origin).
- [ ] **Packing List** (net/gross weight, dimensions, package marks, container/seal numbers).
- [ ] **Bill of Lading (Ocean)** or **Airway Bill (Air)** issued by carrier.
- [ ] **Shipping Bill / Export Customs Declaration** filed with port customs.
- [ ] **Certificate of Origin** (Non-Preferential or FTA Preferential CoO where tariff concessions apply).
- [ ] **Marine / Cargo Insurance Certificate** (mandatory for seller under CIF / CIP Incoterms).

## Sector-Specific Regulatory Certificates (If Applicable)
- [ ] Phytosanitary / Veterinary Health Certificate (agricultural & food exports).
- [ ] Pre-shipment Inspection / Quality Certificate / BIS or CE Conformity Certificate.
- [ ] Material Safety Data Sheet (MSDS) & Dangerous Goods Declaration (chemical/battery shipments).
- [ ] Dual-use Export Control License (semiconductors, encryption, aerospace hardware).
