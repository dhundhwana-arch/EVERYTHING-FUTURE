# EUV Lithography — Standalone Technical Glossary

**Module:** `011_EUV_LITHOGRAPHY` | **Verification Status:** `VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **EUV (13.5 nm)** | Extreme ultraviolet light generated by CO2 laser-heated tin plasma used to pattern leading-edge chips. |
| **Numerical Aperture (NA)** | Optical metric measuring acceptance angle of projection optics (0.33 NA standard; 0.55 NA High-NA). |
| **Rayleigh Criterion** | Minimum printable feature size CD = k1 * lambda / NA. |
| **Depth of Focus (DOF)** | Axial focus tolerance DOF = k2 * lambda / NA^2, shrinking quadratically as NA increases. |
| **Stochastic Defect** | Random patterning failure caused by photon shot noise and chemical variability at low EUV photon counts. |
