# Biotechnology — Standalone Technical Glossary

**Module:** `029_BIOTECHNOLOGY` | **Verification Status:** `VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **CRISPR-Cas9** | Programmable RNA-guided endonuclease enabling targeted DNA editing (Jinek/Doudna/Charpentier, 2012). |
| **AlphaFold** | Deep-learning system predicting 3D protein structures from amino acid sequences at atomic accuracy. |
| **GC Content** | Percentage of guanine (G) and cytosine (C) bases in a DNA/RNA sequence affecting thermal stability. |
| **Codon** | Triplet of nucleotides encoding a specific amino acid or translation stop signal. |
