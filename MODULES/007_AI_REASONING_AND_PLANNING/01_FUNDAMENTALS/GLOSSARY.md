# AI Reasoning and Planning — Standalone Technical Glossary

**Module:** `007_AI_REASONING_AND_PLANNING` | **Verification Status:** `PARTIALLY_VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **Heuristic Search** | Guided state-space search (e.g., A*, MCTS) using admissible cost-to-go estimates. |
| **SAT / SMT Solver** | Automated decision procedures for Boolean satisfiability and logical theories. |
| **Chain-of-Thought** | Explicit intermediate reasoning steps generated prior to a final answer. |
| **Verification-Guided Search** | Using an external verifier or compiler to prune invalid reasoning branches. |
