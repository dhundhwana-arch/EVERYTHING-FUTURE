# Deep Learning — Standalone Technical Glossary

**Module:** `005_DEEP_LEARNING` | **Verification Status:** `PARTIALLY_VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **Backpropagation** | Reverse-mode automatic differentiation computing loss gradients with respect to network weights. |
| **Residual Connection** | Identity skip pathway easing gradient flow in very deep networks (ResNet). |
| **Layer Normalization** | Stabilizing activations across feature dimensions during training. |
| **Quantization** | Reducing weight/activation precision (e.g., FP16 to INT8/INT4) to cut memory and energy. |
