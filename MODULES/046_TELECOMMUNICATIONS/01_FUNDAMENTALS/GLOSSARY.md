# Telecommunications — Standalone Technical Glossary

**Module:** `046_TELECOMMUNICATIONS` | **Verification Status:** `PARTIALLY_VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **Shannon Capacity** | Theoretical maximum error-free channel bit rate C = B * log2(1 + SNR). |
| **OFDM** | Orthogonal Frequency-Division Multiplexing dividing spectrum into closely spaced orthogonal subcarriers. |
| **DWDM** | Dense Wavelength-Division Multiplexing carrying dozens of optical channels over a single fiber. |
