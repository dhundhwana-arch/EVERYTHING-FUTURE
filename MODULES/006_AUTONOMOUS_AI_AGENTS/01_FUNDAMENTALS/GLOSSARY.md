# Autonomous AI Agents — Standalone Technical Glossary

**Module:** `006_AUTONOMOUS_AI_AGENTS` | **Verification Status:** `VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **ReAct Loop** | Interleaved Reasoning and Acting cycle where observations update subsequent actions. |
| **Tool Calling** | Structured invocation of external APIs, calculators, databases, or code interpreters. |
| **State Machine** | Formal graph of discrete states and transitions governing deterministic agent execution. |
| **Action Budget** | Hard upper limit on steps, tokens, or external tool calls to prevent runaway loops. |
