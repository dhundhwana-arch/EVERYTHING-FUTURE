# Machine Learning — Standalone Technical Glossary

**Module:** `004_MACHINE_LEARNING` | **Verification Status:** `VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **Gradient Descent** | Iterative first-order optimization algorithm minimizing a differentiable loss function. |
| **Cross-Validation** | Resampling procedure partitioning data into k folds to estimate generalization error. |
| **Bias-Variance Tradeoff** | Balance between underfitting (high bias) and sensitivity to training noise (high variance). |
| **Regularization** | Penalty terms (L1/L2) added to loss functions to prevent overfitting. |
| **R-Squared** | Coefficient of determination measuring variance explained by a regression model. |
