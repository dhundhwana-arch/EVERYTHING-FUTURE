# Disaster Management — Standalone Technical Glossary

**Module:** `061_DISASTER_MANAGEMENT` | **Verification Status:** `PARTIALLY_VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **Early Warning Lead Time** | Time elapsed between hazard detection/alert issuance and physical impact on communities. |
| **Return Period** | Statistical average recurrence interval between extreme events of a given magnitude (e.g., 100-year flood). |
| **Incident Command System** | Standardized hierarchical emergency-response coordination structure. |
