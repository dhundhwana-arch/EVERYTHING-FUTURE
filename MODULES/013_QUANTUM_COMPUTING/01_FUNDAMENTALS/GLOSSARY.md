# Quantum Computing — Standalone Technical Glossary

**Module:** `013_QUANTUM_COMPUTING` | **Verification Status:** `VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **Qubit** | Two-level quantum system existing in linear superposition alpha|0> + beta|1> with |alpha|^2 + |beta|^2 = 1. |
| **Entanglement** | Non-classical correlation between multi-qubit states (e.g., Bell state (|00>+|11>)/sqrt(2)). |
| **Surface Code** | Topological quantum error-correcting code encoding logical qubits on a 2D lattice of physical qubits. |
| **Decoherence** | Loss of quantum phase information due to environmental coupling (characterized by T1 and T2 times). |
| **Threshold Theorem** | If physical gate error lies below a critical threshold, logical error decreases exponentially with code distance. |
