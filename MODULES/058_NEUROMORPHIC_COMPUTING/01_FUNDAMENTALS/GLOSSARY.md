| Term | Clear Technical Definition |
| :--- | :--- |
| **Spiking Neural Network (SNN)** | Neural model communicating via discrete timed spikes rather than continuous floating-point activations. |
| **In-Memory Computing** | Performing multiply-accumulate operations directly inside memory arrays to avoid von Neumann data movement. |
