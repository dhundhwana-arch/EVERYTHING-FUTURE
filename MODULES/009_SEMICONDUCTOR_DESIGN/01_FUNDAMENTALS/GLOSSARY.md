# Semiconductor Design — Standalone Technical Glossary

**Module:** `009_SEMICONDUCTOR_DESIGN` | **Verification Status:** `VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **CMOS** | Complementary Metal-Oxide-Semiconductor logic pairing nMOS and pMOS transistors for low static power. |
| **RTL (Register Transfer Level)** | Hardware abstraction modeling synchronous digital circuits in Verilog/VHDL. |
| **EDA (Electronic Design Automation)** | Software suites for synthesis, place-and-route, static timing, and verification. |
| **ISA (Instruction Set Architecture)** | Abstract interface between software and processor hardware (e.g., RISC-V). |
| **Dynamic Power** | Switching power P = alpha * C * V^2 * f dissipated when charging/discharging node capacitances. |
