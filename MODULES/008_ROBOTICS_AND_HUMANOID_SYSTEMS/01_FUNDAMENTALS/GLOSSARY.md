# Robotics and Humanoid Systems — Standalone Technical Glossary

**Module:** `008_ROBOTICS_AND_HUMANOID_SYSTEMS` | **Verification Status:** `VERIFIED` | **Last Verified:** 2026-11-19

| Term | Clear Technical Definition |
| :--- | :--- |
| **Inverse Kinematics (IK)** | Computing joint angles required to place a robot end-effector at a target pose. |
| **Degrees of Freedom (DOF)** | Number of independent parameters defining a mechanism's configuration. |
| **ROS 2** | Open-source Robot Operating System middleware using DDS for real-time distributed robotics. |
| **Sim-to-Real Gap** | Performance discrepancy between policies trained in physics simulators and physical hardware. |
